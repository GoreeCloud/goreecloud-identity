# GoreeCloud Identity Security Controls

This record summarizes the control families that must be evidenced before GoreeCloud Identity can be promoted to Stable.

## Control families

- Authentication correctness and abuse resistance.
- Application-owned authorization boundaries.
- Administrative least privilege and individual accountability.
- Session creation, expiration, revocation, and logout behavior.
- Recovery, authenticator, passkey/WebAuthn, and MFA behavior when enabled.
- Secret separation and protected signing/encryption material.
- Dependency, vulnerability, source, and build integrity.
- Private network publication and backend exposure control.
- Structured, minimized audit and operational logging.
- Independent availability monitoring and safe alerts.
- Backup, isolated restoration, break-glass administration, and rollback.
- Glaze UI accessibility and security-message clarity.

Wardveil Security by GoreeCloud is the presentation identity for verified security controls. It is not itself a technical control.
