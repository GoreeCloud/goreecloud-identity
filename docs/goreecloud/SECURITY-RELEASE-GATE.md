# GoreeCloud Identity Security Release Gate

Security release acceptance requires the exact candidate to pass applicable inherited and GoreeCloud source checks, contain no known unaddressed release-blocking vulnerabilities, preserve authentication/authorization/session/recovery semantics, keep secrets out of source/logs, demonstrate private publication, and prove backup/restore, break-glass, monitoring, representative application integration, and rollback behavior.

A skipped or unavailable mandatory control is not treated as passed without a documented GoreeCloud exception.
