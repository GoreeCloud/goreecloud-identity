# GoreeCloud Identity Known Limitations

The current hardening branch is source-level work only. It does not yet prove complete visual Glaze UI conformance across every upstream component, target-environment deployment readiness, independent monitoring, real GoreeCloud application SSO behavior, backup restoration, signing-material continuity, break-glass administration, or rollback.

These limitations are release blockers, not deferred cosmetic tasks. They must be resolved or explicitly approved through the applicable GoreeCloud exception process before Stable production acceptance.
